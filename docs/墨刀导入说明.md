# 墨刀导入与演示说明

## 当前原型包含什么

- `home.html`：浏览最新信息、按寻物/招领筛选、搜索并进入详情。
- `publish.html`：选择寻物或招领，填写类别、时间、地点、描述和联系方式；缺项时提示。
- `search.html`：按关键词和信息类型过滤结果，展示空结果状态。
- `detail.html`：查看详情、点击展示联系方式、将信息标记为已解决。
- `success.html`：确认发布内容，并继续查看新信息详情或返回首页。

发布的新信息会保存在当前浏览器的 `localStorage`，并在本地首页、搜索结果和详情中演示；已解决状态也保存在当前浏览器。本原型适合需求评审、课堂演示和导入后继续调整，不是已部署的小程序服务。不同设备之间不共享数据，也没有账号权限、服务器数据库或真正的联系方式访问控制；正式上线需要另行开发服务端、身份与权限规则、隐私保护和数据维护功能。

## 导入墨刀

**注意：HTML 的 `viewport` 只设置浏览器如何缩放网页，不会自动创建墨刀原型画布。** 如果把 HTML 文件直接当演示页面打开，或导入后只出现空项目页，演示器就可能提示「页面无画布」。请先在墨刀新建「手机端原型」项目/页面，再使用「HTML 转原型」将页面转成原型画布；如果导入器提供目标尺寸，设置为 **393 × 852 px**。本目录五个 HTML 页面的根容器均明确设置为 393 × 852 px，视觉样式也内嵌在各自文件中，逐页导入不依赖独立 CSS 文件。页面使用墨绿、暖纸白和朱砂橙的校园档案视觉。

建议先导入 `home.html` 确认页面进入画布且尺寸正确，再逐页导入其余四个页面；导入后逐页检查文字、布局和按钮。若页面跳转没有自动转换，请在墨刀编辑区按下列关系补上热点：

1. 首页搜索框/搜索按钮 → 搜索结果；首页信息卡片 → 信息详情；「发布信息」→ 发布信息。
2. 搜索结果卡片 → 信息详情；返回入口 → 首页。
3. 发布表单提交 → 发布成功；表单缺项状态应能展示字段提示。
4. 发布成功「查看详情」→ 信息详情；「返回首页」→ 首页。
5. 信息详情「返回信息列表」→ 首页；联系和标记已解决操作应有对应状态反馈。

导入后若仍提示「页面无画布」，回到编辑器确认当前项目中有手机页面画布，并确认 HTML 转换的结果已放到该画布，而不是只新增了一个空白页或网页预览链接。演示设置选择手机/真机预览；长列表页面要允许纵向滚动。具体入口、可上传文件类型以及脚本交互保留程度可能随墨刀账号和版本变化。若导入器只转换视觉组件，就在墨刀里补连交互。页面中的 Tailwind 和图标资源仍需联网加载。

## 演示顺序

从首页点击一条信息进入详情；回首页搜索「校园卡」并从结果打开详情；最后发布一条测试信息，在成功页查看详情，再回首页确认新信息出现。可在详情页标记已解决后返回列表查看状态。

墨刀官方介绍：[HTML 转原型](https://modao.cc/ad/html-to-prototype)；导入使用方式参考[多页面 HTML 导入说明](https://modao.cc/ad/blog/llm-multi-page-html-import-edit.html)。
